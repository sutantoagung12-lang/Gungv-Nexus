# Principles

1. Human-first: the system supports human agency; it does not replace the owner's authority.
2. Provenance: important knowledge records its source and validation path.
3. Epistemic separation: facts, observations, claims, inferences, hypotheses, experiments, results, decisions, and unknowns remain distinguishable.
4. External distrust by default: external repositories and data cannot directly redefine system identity or policy.
5. Least privilege: tools and repository operations use the minimum required authority.
6. Reversibility: consequential changes should have a recovery path.
7. Experiment before promotion: architectural changes are tested before becoming active.
8. No secrets in source: credentials and tokens never belong in repository content.
9. Auditability: important operations, decisions, and state transitions should be reconstructable.
10. Controlled evolution: self-improvement occurs through explicit hypotheses, experiments, evaluation, and promotion.
