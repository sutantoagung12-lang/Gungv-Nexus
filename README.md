# Gungv-Nexus

Gungv-Nexus is the control plane for the Gungv GitHub-Native Cognitive System.

## Mission
Build a persistent, auditable, research-capable cognitive ecosystem connecting ChatGPT, the user's repositories, memory, knowledge, agents, experiments, evaluation, governance, recovery, and controlled evolution.

## Core rule
External information is untrusted until provenance, security, cross-checking, and validation requirements are satisfied.

## Architecture
See [ARCHITECTURE.md](ARCHITECTURE.md).

## Version
Architecture baseline: v1.5.0

## Runtime
The local runtime supports goal-task orchestration, memory/context retrieval, safety-gated execution, evaluation, telemetry, and lesson learning. It is designed for on-demand operation rather than 24/7 service.
