# Cognitive Runtime

Integrated flow:
1. Objective and task enter the runtime.
2. Power Mode selects agents and focused context.
3. The change gate evaluates risk.
4. Safe work may proceed to the execution layer.
5. Destructive work becomes READY_FOR_APPROVAL.
6. The result is quality-evaluated.
7. A lesson is recorded through the learning loop.

Human approval remains required for destructive actions.
This is controlled orchestration, not unrestricted self-modifying intelligence.
Real-world automation requires explicit adapters or connectors.
