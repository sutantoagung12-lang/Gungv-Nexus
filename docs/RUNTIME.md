# Runtime

The repository contains an offline-first Python runtime implementing the first executable slice of the blueprint: context compilation, memory, knowledge, epistemic classification, provenance, agent routing, security policy, experiments, evaluation, recovery, and telemetry.

Run:

    python nexus.py health
    python nexus.py route "analyze the repository architecture"
    python nexus.py inspect "delete repository"

The runtime deliberately does not contain credentials or autonomous destructive GitHub operations. External data remains untrusted until validated.
