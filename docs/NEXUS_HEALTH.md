# Nexus Health Report

The health report is generated by `scripts/nexus_health.py`.

Schema: `nexus-health/v1`

Statuses:
- PASS: local contract is satisfied.
- BLOCKED: capability is intentionally unavailable until its activation gates are satisfied.
- READY: activation gates currently permit the capability.
- FAIL: an expected safety/runtime invariant is broken.

The report is deterministic and does not perform network, browser, credential, Android Chrome, or repository-write operations.

Google Cloud Build generates `health/nexus-health.json` during validation. The file is a build artifact; its presence alone is not evidence that the build succeeded. Review the build result and report contents together.
